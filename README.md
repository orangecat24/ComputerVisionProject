# ComputerVisionProject
Final project for the Computer Vision course at UPT TIRANA. 

Members : Gleris Xhoxha , Renisa Kasa ,  Andri Pashollari

Description: 

This project focuses on image classification and image segmentation using the Oxford 17 Flowers Dataset which contains flower images belonging to 17 different classes and corresponding segmentation masks used for semantic segmentation tasks.

Since we have previous experience with deep learning, we did some research and decided to use 3 state of the art CNN architectures used for Image Classification :
ResNet50, VGG19 And EfficientNetB0 .

Model performance was evaluated using:

Validation Accuracy
Validation Loss
Confusion Matrix
Classification Report

= Three different segmentation approaches were implemented:

U-Net
SegNet
K-Means Segmentation with different parameter K numbers

Conclusions

This project demonstrates the effectiveness of modern deep learning architectures for image classification and segmentation tasks. The comparison between ResNet50, VGG19, and EfficientNetB0 highlights the strengths of transfer learning, while U-Net and SegNet showcase the capabilities of deep learning for semantic segmentation. Additionally, K-Means segmentation provides a classical computer vision baseline for comparison against deep learning approaches.
